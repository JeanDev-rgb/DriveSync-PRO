# DriveSync PRO 🚀

**Software premium por línea de comandos para gestión y sincronización masiva de Google Drive. Desarrollado por JeanDev bajo la marca Streamify+.**

DriveSync PRO es una herramienta CLI de alto rendimiento diseñada para transferir archivos pesados de forma estructurada, saltándose las limitaciones, cuelgues o bloqueos de descarga del navegador tradicional.

### ⚙️ Características Principales

* **Transferencias Directas:** Copia y clonación de datos masivos de Drive a Drive, o descargas directas de Drive a almacenamiento Local.
* **Alto Rendimiento:** Código optimizado para procesar decenas de gigabytes a velocidades máximas sin consumir recursos excesivos de tu ordenador.
* **Interfaz Premium:** Consola (TUI) limpia e interactiva con navegación por directorios.
* **Automatización:** Detección automática de unidades conectadas, visualización de progreso detallado y cálculo de velocidades en tiempo real.
